# Ubuntu 24.04 Dry-Run Validation - 2026-06-01

This validation runs on a disposable GitHub Actions `ubuntu-24.04` runner.

## Scope

Validated:

- shell syntax for `bootstrap.sh`
- shell syntax for `scripts/check-no-secrets.sh`
- accidental-secret scan
- `config.example.env` loading
- `bootstrap.sh --dry-run --config config.example.env`

Not validated by this dry-run:

- package installation
- UFW mutation
- sysctl mutation
- iptables mutation
- WireGuard key generation
- OpenVPN Easy-RSA PKI generation
- systemd service activation
- real client handshake

## Why Dry-Run First

The full bootstrap changes host networking, firewall, NAT, VPN services, and
generated client keys. Dry-run validation is safe for CI and gives maintainers a
reviewable plan before they run the installer on a disposable VPS.

Full install validation should still be performed on a disposable Ubuntu 24.04
VPS before closing the full-install validation milestone.
